# Portfolio Neo Brutalism Skill

Use this skill when working on the portfolio UI, especially when the user asks to redesign, improve, refactor, or make the interface look less AI-generated.

## Project Stack

* Framework: Next.js
* Language: TypeScript
* Styling: Tailwind CSS
* UI target: Personal developer portfolio
* Design direction: Mature Neo Brutalism

## Main Goal

Improve the portfolio UI so it feels bold, human-made, professional, and recruiter-friendly.

The design must not look like a generic AI-generated SaaS landing page.

## Design Reference

Before changing UI code, read `design.md` in this skill folder and follow the design system, section rules, component rules, and anti-patterns written there.

## Rules

* Do not change business logic.
* Do not break routes.
* Do not remove important content.
* Do not rewrite the whole project unless necessary.
* Focus on UI, layout, spacing, typography, responsive behavior, Tailwind classes, components, and visual consistency.
* Keep the portfolio suitable for a Mobile Developer / Full-Stack Developer profile.
* Prefer clean and mature Neo Brutalism, not childish or overly colorful brutalism.
* Use strong visual hierarchy.
* Make the UI easy to scan for recruiters.
* Keep mobile-first responsiveness.

## Workflow

1. Inspect the current page structure and relevant components.
2. Identify UI parts that feel AI-generated or too generic.
3. Explain the planned changes briefly before editing.
4. Update the UI section by section.
5. Keep Tailwind classes readable and maintainable.
6. After editing, summarize changed files and design improvements.

## Priority Sections

Improve these sections first:

1. Navbar
2. Hero
3. About
4. Skills
5. Experience
6. Projects
7. Contact
8. Footer

## Tailwind Style Direction

Use patterns like:

* `border-2 border-black`
* `border-4 border-black`
* `shadow-[4px_4px_0px_#000]`
* `shadow-[6px_6px_0px_#000]`
* `hover:translate-x-[2px]`
* `hover:translate-y-[2px]`
* `hover:shadow-[2px_2px_0px_#000]`
* Flat solid backgrounds
* Clear black text
* Off-white base background
* Limited accent colors

Avoid:

* Excessive gradients
* Glassmorphism
* Soft blurred shadows
* Neon glow
* Floating blobs
* Overused AI landing page visuals
* Too many badges
* Generic project cards
* Overly dramatic copywriting
